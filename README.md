# Python Task 2

This is my Python Task 2. It has practice programs and one project.

## Project

The project is a Student Management System.
The file name is student_record_management.py

It can add a student, view all students, search a student by roll number and find the average marks.
The data is saved in students.txt

## How to run

Open the terminal and type:

python student_record_management.py

Then enter a number from 1 to 5.

## Concepts used

Variables, lists, dictionaries, if else, loops, functions, file handling and try except.
